# PhishGuard ML Documentation

This directory contains the detailed engineering documentation for the project.

## Documents

- [Project Structure](project-structure.md): exact repository paths and the responsibility of each file.
- [Architecture](architecture.md): request flow, model inference, heuristics, and deployment boundaries.

## Documentation Principles

The documentation describes the repository as it exists. Generated model files are artifacts, compatibility launchers are identified as such, and the canonical development commands are separated from retained legacy files.
